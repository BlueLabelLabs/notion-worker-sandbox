# Engagement Codes Standards (Process Library, Status Accurate, 2026-04-23)

they record budget and/or scope adjustments. Example: BL900.01 | Product Strategy & Design; BL900.01.CR01 | Budget increase; BL900.02 | Administration Portal.
DPPT file names follow "BL###.## - <Title> - DPPT v6.x" (template title "BL###.## - [Title] - DPPT v6.3"); Deal titles follow "BL###.## | Client Name Engagement Title".
